# NutriAI (MVP)

App React Native (Expo) com fluxo completo de:
- onboarding com objetivos e metas,
- dashboard de calorias + água,
- captura por foto (simulada),
- dieta diária,
- progresso,
- notificações,
- perfil/configurações.

## Rodar

```bash
npm install
npm start
```

Depois abra no Expo Go (Android/iOS) ou web.
